# 📌 Microservicio: cy-loan-requests

Microservicio para la **gestión de solicitudes de préstamos** de CrediYa, implementado con **Spring Boot 3**, **WebFlux** y el **plugin scaffold de Bancolombia** bajo el enfoque de **Arquitectura Limpia**.

---

## ⚙️ Tecnologías utilizadas

- **Java 21**
- **Spring Boot 3**
- **Spring WebFlux** (programación reactiva)
- **R2DBC + PostgreSQL**
- **Lombok** (simplificación de código)
- **Clean Architecture (Scaffold Bancolombia)**
